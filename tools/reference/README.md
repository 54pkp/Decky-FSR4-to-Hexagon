# Synthetic CPU reference

This package builds and checks one fixed `float32` ONNX graph:
`Conv -> Add -> ReLU`, with input and output shape `[1, 1, 4, 4]`. The three
test inputs are zero, a literal pattern, and a nonzero input from seed
`20260921`. Expected outputs come from a direct NumPy convolution formula.
Elementwise comparison uses `rtol=0` and `atol=1e-6`, declared before runtime.

Create the isolated Windows environment and run the focused checks from the
repository root:

```powershell
& 'C:\Path\To\python.exe' -m venv local/venvs/reference
.\local\venvs\reference\Scripts\python.exe -m pip install --isolated -r tools/reference/requirements-reference.txt
.\local\venvs\reference\Scripts\python.exe -m unittest discover -s tests/reference -p "test_*.py" -v
.\local\venvs\reference\Scripts\python.exe tools/reference/small_graph.py verify
```

These commands do not install their own dependencies. Create the environment
from the checked-in requirements only when it is absent; do not overwrite an
existing environment. Calibration export additionally requires an existing,
non-reparse parent, a new output directory, and an output path with no
whitespace.

Regenerate the small checked-in model with `small_graph.py build`. Tests require
the regenerated bytes and SHA-256 to match the fixture. This synthetic Windows
CPU result is not FSR4 equivalence, QAIRT/QNN conversion, HTP execution, device
validation, game validation, or performance evidence.

Known issue: failed export cleanup can delete a same-named directory created by
a concurrent task. Until that ownership bug is fixed, never run two P5 exports
against the same target; give every run a fresh, exclusive output directory.
