# 显式连续目标提示（可选）

普通单次任务使用 [SINGLE_RUN_PROMPT](SINGLE_RUN_PROMPT.md)。本页只是供用户主动选择的模板，阅读或维护它不授权创建 Goal。

官方说明将 Goal 用于跨轮次推进一个有可验证终点的目标；应选有边界的目标，而不是无限待办列表。参见 [OpenAI：Follow a goal](https://learn.chatgpt.com/use-cases/follow-goals)（2026-09-22 核对）。是否提供该入口以当前宿主为准，本项目不自动修改功能开关。

先选定目标和有限批次子集，例如“关闭R中的目录发布竞争问题”，而不是“直到整个项目完成”。替换占位符后，用户可显式以 `/goal` 提交：

```text
在 Windows 上持续完成 Decky-FSR4-to-Hexagon 的目标：<一个具体目标>。
本次只包含批次：<从当前 STATUS 选择的有限叶子ID列表>。
可验证终点：<必须通过的实现、测试及交付条件>。

按 docs/ai/SINGLE_RUN_PROMPT.md 的仓库定位、模型角色、环境隔离、审阅、证据和Git规则执行；区别在于本次我明确请求Goal，可以在每个小批次完成后继续冻结范围内的下一批。开始前读取AGENTS、STATUS、MULTI_AGENT_WORKFLOW及相关R/F/E计划，确认依赖和现有现场。H/P历史项不重启，不自动纳入D设备批次或未来新增任务。

启动时冻结上述范围，不自行追加整个后续路线。每批只解决一个可验收行为，完成实现、相关测试、Astra审阅/必要复核、一份短记录和STATUS更新；在授权范围内由协调者提交/推送。公开文档不依赖本机私有路径，失败/skipped/not_run如实保留。

缺某分支输入时可推进冻结范围内已满足依赖的独立项；需要新权限、重要选择或扩大范围时请求最小决定。未达到终点不能标complete，未做设备/游戏检查仍not_run。Goal状态遵循宿主提供的机制，不因更新文档擅自暂停或结束未完成目标。全部冻结验收完成后停止，不转入其它阶段，不创建定时任务。
```
